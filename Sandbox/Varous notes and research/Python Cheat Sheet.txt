Running program:

Ctrl+F2 = Stop the running program
Shift+F9 = Run in Debug mode
F9 = Resume after hitting a breakpoint
F8 = Step over
F7 = Step into

What many people do is:

Run (Shift+F10)
See a problem
Ctrl+F2 to stop
Set a breakpoint
Shift+F9 to debug

A faster alternative while learning is to simply leave a breakpoint set near the top of main() and always start with Shift+F9. The overhead is usually small, and you can inspect variables whenever you need.
